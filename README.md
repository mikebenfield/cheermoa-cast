# 치어 모아 — Cast receiver

The page a Google TV / Chromecast loads when the 치어 모아 iPhone app casts to it. It plays YouTube, TikTok and
Instagram videos in the platforms' own embedded players, as the phone tells it to (custom namespace
`urn:x-cast:com.michaelbenfield.cheermoa`). Source: `CastReceiver/` in the app's repository.
